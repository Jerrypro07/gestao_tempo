# ⏱️ Gestão de Tempo

Aplicação web desenvolvida para auxiliar no **gerenciamento de tarefas e organização do tempo**.

O projeto permite cadastrar tarefas, acompanhar seu andamento e organizar as atividades do dia de forma simples e prática.

## 🎯 Objetivo

O objetivo do projeto é desenvolver uma aplicação que ajude o usuário a:

* Organizar suas tarefas;
* Definir atividades;
* Acompanhar tarefas em andamento;
* Marcar tarefas como concluídas;
* Gerenciar melhor o tempo;
* Visualizar suas atividades em um único lugar.

## 🚀 Funcionalidades

## 💻 Como executar o projeto

### 1. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Entrar na pasta

```bash
cd gestao-tempo
```

### 3. Criar um ambiente virtual

```bash
python -m venv .venv
```

### 4. Ativar o ambiente virtual no Windows

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Instalar as dependências

```bash
pip install -r requirements.txt
```

### 6. Executar a aplicação

```bash
python app.py
```

Depois, abra no navegador:

```text
http://127.0.0.1:5000
```
